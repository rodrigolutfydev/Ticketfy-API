# Roteiro de Testes Manuais - Ticketfy

## 1. Acesso
- Verificar o carregamento da página inicial.
- Conferir a navegação entre as páginas.
- Verificar a visualização em dispositivos móveis.

## 2. Cadastro e Login
- Testar o cadastro de usuários.
- Verificar o login com dados válidos.
- Testar o comportamento com dados incorretos.
- Verificar a recuperação de senha.

## 3. Eventos
- Conferir a listagem de eventos.
- Testar a busca por eventos.
- Verificar os detalhes de cada evento.

## 4. Ingressos
- Verificar a seleção de ingressos.
- Conferir o resumo da compra.
- Verificar a confirmação do pedido.
- Conferir os ingressos disponíveis na conta.

## 5. Objetivo
Organizar verificações manuais para auxiliar na identificação de possíveis problemas e melhorar a qualidade da plataforma Ticketfy.
